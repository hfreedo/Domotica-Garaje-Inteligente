# Procedencia

El panel C# se adaptó del proyecto local «Medición de PH TDS del Agua», proporcionado por el usuario como referencia, cuya licencia permite adaptación educativa. Se conservan como referencia de procedencia los documentos del proyecto original; esta entrega no copia sus credenciales, configuraciones privadas ni ejecutables.

El firmware, protocolo, servidor del garaje, interfaz y pruebas se desarrollaron para esta maqueta. Dependencias: Arduino AVR Core / Servo / EEPROM, Python, pyserial, .NET Windows Desktop y QRCoder. Sus licencias siguen perteneciendo a sus respectivos titulares. El portable de Python incluye licencias y avisos de las dependencias que distribuye PyInstaller. ngrok se descarga y configura por separado.

No se modificó el proyecto de pH/TDS ni el proyecto de gestión médica.

El release 1.0.2 incluye CH341SER.EXE original de WCH/Nanjing Qinheng Microelectronics Co., Ltd.; su procedencia y hash están en `support/ch340/procedencia.json`. Conserva los términos de su fabricante. La licencia pública del código propio del proyecto todavía no está definida por sus titulares.
